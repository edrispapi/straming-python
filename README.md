# سامانه آموزش آنلاین با کلاس زنده و آرشیو ویدئو

## معرفی پروژه

این پروژه یک **سامانه آموزش آنلاین** پیشرفته است که امکان برگزاری کلاس زنده، آرشیو ویدئو، جستجوی هوشمند، مدیریت پرداخت و مانیتورینگ بلادرنگ را فراهم می‌کند. قابلیت‌های پلتفرم مناسب راه‌اندازی سرویس‌هایی مانند آموزش مجازی، کلاس‌های وبینار و دوره‌های تصویری است.

## فناوری‌ها و ماژول‌های کلیدی

- **Django REST Framework**  
  توسعه API امن و مقیاس‌پذیر برای مدیریت کاربران، دوره‌ها، آرشیو ویدئو و عملیات مدیریتی پروژه.

- **Celery + RabbitMQ**  
  اجرای وظایف پس‌زمینه (ارسال ایمیل، پردازش فایل، گزارش‌گیری) و مدیریت صف‌های پیام میان سرویس‌ها.

- **Redis**  
  کشینگ داده‌، مدیریت Session کاربران و بهبود زمان پاسخگویی سیستم.

- **PostgreSQL**  
  پایگاه داده رابطه‌ای برای اطلاعات ساختاری (کاربر، دوره‌ها، تراکنش و...).

- **MongoDB**  
  ذخیره داده‌های غیرساختاریافته مانند لاگ‌ها، گزارش‌های پیشرفته و اطلاعات تحلیلی.

- **NGINX (Streaming Server & Reverse Proxy)**  
  مدیریت ترافیک HTTP، پراکسی درخواست‌ها به اپلیکیشن، پخش زنده و آرشیو ویدئو.

- **Arvan Cloud**  
  سرویس ابری برای مدیریت پخش ویدئو، راه‌اندازی CDN و ارتقای کیفیت تحویل محتوا.

- **FFmpeg**  
  پردازش، تبدیل و آماده‌سازی ویدئوها جهت انتشار و آرشیو.

- **Django Channels**  
  پیاده‌سازی ارتباط بلادرنگ (چت، اعلام حضور، پرسش و پاسخ حین کلاس).

- **DRF SimpleJWT**  
  مدیریت امن احراز هویت کاربران با توکن JWT.

- **Zarinpal SDK**  
  اتصال به درگاه زرین‌پال برای پرداخت آنلاین شهریه یا ثبت‌نام.

- **Grafana & Prometheus**  
  مانیتورینگ سلامت سرورها و سرویس‌ها، تحلیل داده‌ها و رسم نمودارهای بلادرنگ.

- **Sentry**  
  رصد و ثبت خطاهای برنامه‌نویسی به صورت Realtime.

- **OpenSearch / ElasticSearch**  
  جستجوی قدرتمند بین دوره‌ها، ویدئوها و داده‌های سیستم.


## قابلیت‌های اصلی پروژه

- ثبت‌نام و احراز هویت با امنیت بالا (JWT)
- مشاهده، خرید و شرکت در دوره‌های آنلاین
- کلاس زنده با پشتیبانی استریم و پاسخ بلادرنگ به چت
- آرشیو و مشاهده مجدد ویدئوها
- اتصال آسان به درگاه پرداخت و تسویه شهریه
- جستجوی سریع دوره‌ها و ویدئوها
- مانیتورینگ لاگ‌ها، رویدادها و وضعیت سامانه توسط مدیر سیستم

## ساختار پروژه

- `users/` — مدیریت کاربران، احراز هویت و جلسات (Sessions)
- `courses/` — اطلاعات دوره‌ها، جلسات زنده، ویدئو آرشیو
- `payments/` — مدیریت تراکنش و پرداخت (Zarinpal)
- `streaming/` — مدیریت ویدئو، استریم، برقراری ارتباط با Arvan Cloud و FFmpeg
- `livechat/` — ماژول ارتباط بلادرنگ (WebSocket)
- `monitoring/` — اتصالات به Prometheus، Grafana و Sentry  
- `search/` — جستجو روی دوره‌ها و محتوا با Elastic/OpenSearch
- `docker-compose.yml` — اجرای سرویس‌ها و وابستگی‌ها
- `deploy/nginx.conf` — کانفیگ NGINX برای پراکسی و Streaming
